# Video styles in this repo: pick one before you start

| Style | Skill | What it looks like | Use when |
|---|---|---|---|
| **House style 3D** (current default) | `house-style-3d` | Our own 3D cast: skin tones for everyone, black-head hero (Kai); matte, varied, live hands; designed coverage, heavy VFX, 2D/2.5D inserts | "our style", "new style", tests, anything not tied to a named channel |
| 3D engine (generic) | `story-video-3d` | Three.js in Remotion, voice, timing, sound; the base the house style builds on | engine questions, or setting up a new user from nothing |
| 2D genre style | `nexus-what-if` + `nexus-remotion` | Flat 2D black-head characters, genre look (episodes 01–03) | only if the user asks for the old 2D look |
| A named channel | (made when the user names it) | That channel's branding, characters, intro and outro | once the user says which channel |
